# 🏋️ B14-A6-Fit Log

---

### 1. 📖 Description

B14-A6-Fit Log is a modern and intuitive fitness companion designed to inspire active lifestyles and build consistent workout habits. The application empowers users to seamlessly plan, log, and monitor their daily physical routines with clear insights into estimated duration and calories burned for each exercise. By providing transparent end-of-day progress overviews and real-time activity tracking, FitLog helps fitness enthusiasts stay accountable, measure their performance, and stay motivated on their fitness journey.

---

### 2. 🛠️ Technologies Used

* Next.js (App Router, Server & Client Components)
* TypeScript
* Tailwind CSS
* DaisyUI
* React Context API

---

### 3. ✨ Features

* Browse the Comprehensive Workout Library
* Add Workouts to Daily Plan
* Save Favorite Workouts
* Track Daily Completed Workouts
* View Detailed Exercise Information
